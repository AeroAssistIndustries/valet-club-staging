# The Valet Club: staging site

Staging build of the redesigned site for thevaletclubstyling.com. Single page: `index.html`.

- Staging link: https://aeroassistindustries.github.io/valet-club-staging/
- The page hides itself from search engines on any address other than thevaletclubstyling.com.
- Logo and founder photos load from `images/` when present, otherwise from the current live site. See `images/README.md` before launch.
- `robots.txt` and `sitemap.xml` are written for the live domain.
